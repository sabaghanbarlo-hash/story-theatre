Story Theatre

Paste a story. A character tells it out loud, moves, blinks and talks along with the words.

Ready
Two or more characters, and scenes

Plain text works as it is: one character reads everything. To add more, use these lines:

# Characters (the first one is the storyteller)
@character Kaito | hair=#2a2030, shirt=#2a9d8f, style=short
@character Mia | hair=#6b3a2a, shirt=#e76f51, style=long

# New scene and background (words like night, forest, sea, village, dawn change the setting)
[bg: moonlit forest]

# Dialogue
Mia: “You can’t catch the moon!”
